# PokeAPI

## Descripción del proyecto:
Este proyecto hace parte de las Katas del primer año del Master en ciberseguridad de Prometeo FP. El primer año es transversal por lo que hemos visto las bases del desarrollo web. 
Este ejercicio consistía en usar PokeAPI para renderizar en la app un pokémon aleatorio de los primeros 151, debíamos elegir la imagen que más nos gustara y mostrar un pokemón nuevo cada vez que la pagina se recargara.

## Descripción de la AppWeb
La app web tiene dos partes principales:
### Hero content:
En esta parte se renderiza un pokemon aleatorio con su imagen y nombre, abajo del nombre hay un botón con una pokebola el cuál se debe presionar para guardar el pokemón, en caso de no quererlo hay otro botón en la parte superior del pokemon para pasar al siguiente.
### Barra lateral:
En caso de vista escritorio es una barra lateral donde se almacena una lista con los pokemones capturados, en caso de querer ver la imagen del pokemón sólo hará falta pasar el cursor sobre la misma.

- No permite duplicar los pokemones
- Permite un máximo de seis (6) pokemones (Piensa bien cuáles elegir).

## Tecnologías usadas:
- HTML 5
- CSS 3
- JavaScript Vanilla
